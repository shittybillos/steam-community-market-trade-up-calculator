Chrome extension for CS2 trade-ups directly on Steam Community Market, supporting Beta and classic pages.

### What's new in v0.5.0

- Resize the bench between the compact popup and a 75%-screen view with the ⤢ button in the header.
- Item images for every input (taken from its Steam listing) and every output, including each Doppler/Gamma Doppler gem and phase.
- Includes the v0.4.1 visual refresh.

- Standard ten-input contracts and five-Covert knife/glove contracts.
- Exact listing floats, input cost snapshots, output odds and predicted wear.
- Persistent basket, loaded-page filtering and sorting.
- StatTrak reds from glove collections are blocked from every contract.
- Individual eligible Doppler/Gamma Doppler gems and phases, each with predicted float and wear.
- Finish headers show combined odds; individual phase/gem probabilities are not estimated.

Download the extension ZIP below (not GitHub's source archive), extract it, enable Developer mode at `chrome://extensions`, and choose Load unpacked. To update an existing installation, replace its files, reload the extension and refresh all Steam market tabs.

Listing prices and availability are snapshots. This extension does not purchase items or submit contracts. The bundled catalog is dated October 14, 2026. See the README for limitations and the privacy policy for local storage details.
